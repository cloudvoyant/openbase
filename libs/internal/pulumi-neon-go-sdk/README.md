# `pulumi-neon-go-sdk`

Internal generated Pulumi Go SDK bindings for the official `neondatabase/neon` (`0.19.0-beta.3`) Terraform provider via Pulumi's dynamic `terraform-provider` bridge.

Refresh bindings with `mise run //libs/internal/pulumi-neon-go-sdk:generate` (or workspace `mise run generate`) and check for drift with `mise run //libs/internal/pulumi-neon-go-sdk:generate:check`.

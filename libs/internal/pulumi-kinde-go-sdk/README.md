# `pulumi-kinde-go-sdk`

Internal generated Pulumi Go SDK bindings for the `kinde-oss/kinde` (`0.1.1`) Terraform provider via Pulumi's dynamic `terraform-provider` bridge.

Refresh bindings with `mise run //libs/internal/pulumi-kinde-go-sdk:generate` (or workspace `mise run generate`) and check for drift with `mise run //libs/internal/pulumi-kinde-go-sdk:generate:check`.
